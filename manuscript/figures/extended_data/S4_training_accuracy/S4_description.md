# Extended Data Fig. 4: Training convergence and classification accuracy do not predict alignment

**Extended Data Fig. 4 | All models successfully learn their classification tasks, but classification accuracy does not predict brain or behavioural alignment.**
Epoch-20 test-set classification accuracy (mean ± SEM across three independently trained networks, seeds a/b/c, read directly from each checkpoint's `training_metrics.csv`) as a function of supervisory granularity. The trained model is the same AlexNet-style CustomCNN throughout; only the labels differ. Left panel: coarse conditions (2, 4, 8, 16, 32, 64 classes, log₂-scaled x-axis) for four PCA label sources — AlexNet (`/data/ymehta3/alexnet_pca`, light blue circles), CLIP ViT-L/14 (`/data/ymehta3/clip_pca`, dark blue squares), supervised ViT-L/16 (`/data/ymehta3/vit_pca`, crimson triangles) and DINOv3 ViT-L/16 (`/data/ymehta3/dino_pca`, teal pentagons) — with a small multiplicative jitter per source to separate overlapping markers. Right panel (narrow, shared y-axis): the 1,000-class supervised baseline (`/data/ymehta3/default`, orange bar) with SEM capline. Grey crosses mark the chance accuracy 100 / *k* (%) at each coarse *k* and 0.1 % for 1,000-way; the "Chance" label is inline above the 2-way chance point.

Accuracy decreases monotonically with the number of classes for every label source, as expected. At matched granularity there are large accuracy differences across sources: AlexNet-derived labels yield the easiest tasks (95.9 % at 2-way, 74.1 % at 64-way, averaged across seeds a–c), followed by CLIP (94.6 % at 2-way, 49.7 % at 64-way) and the supervised ViT-L/16 (94.1 % / 57.5 %); DINOv3-derived labels yield the hardest tasks (76.6 % at 2-way, 39.0 % at 64-way). The 1,000-class baseline reaches ≈ 73.9 % top-1 accuracy. Despite this spread, the four sources produce comparable brain and behavioural alignment (Extended Data Fig. 1), so classification accuracy does not track representational alignment at matched granularity.
