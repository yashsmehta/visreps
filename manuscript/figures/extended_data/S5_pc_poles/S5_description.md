# Extended Data Fig. 5: Pole images along the PCA coarse-graining axes

**Extended Data Fig. 5 | Most- and least-activating ImageNet images along the principal components used for coarse-graining.**
Two side-by-side blocks — AlexNet representations (left) and CLIP ViT-L/14 representations (right) — display the top six principal components (PC1–PC6) of each source's FC-layer ImageNet training features. Within each block, rows are PCs and columns are pole images: the five images with the **lowest** projection on that PC are shown on the left (green "Least Activating" sub-header), the five with the **highest** projection on the right (orange "Most Activating" sub-header), separated by a narrow gap column. Each row is labelled in the left margin with the PC index (e.g. "PC 1") and the variance it explains, computed as `eigenvalues[i] / total_variance × 100` from `datasets/obj_cls/imagenet/eigenvectors_{alexnet,clip}.npz`. Pole image identities are loaded from `datasets/obj_cls/imagenet/pca_poles/pca_poles_{alexnet,clip_vit}.csv` and pulled from the ImageNet training set (`IMAGENET_DATA_DIR`); each image is centre-cropped to a square and resized to 224 × 224 with Lanczos resampling. No scores, labels, or decision boundaries are overlaid — the figure shows only the raw images at the poles. The same six PCs are the axes used by the recursive median-split procedure to generate 2-, 4-, 8-, 16-, 32- and 64-class coarse labels for the two corresponding PCA label sources.

The figure is provided so that readers can directly inspect which image content sits at each pole of the axes used for coarse-graining. Together with Extended Data Fig. 1, which shows that all four PCA sources produce comparable brain and behavioural alignment, the panels are intended to illustrate that very different axis content (e.g. colour/texture for AlexNet vs more object-category-like axes for CLIP) can yield the same coarseness effect, consistent with the effect depending on the granularity of the partition rather than its specific semantic content.
