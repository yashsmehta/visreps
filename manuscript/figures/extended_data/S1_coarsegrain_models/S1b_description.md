# Extended Data Fig. 1b: THINGS behavioural alignment across all four PCA label sources

**Extended Data Fig. 1b | The coarse-supervision advantage on human behavioural similarity holds across all four PCA label sources.**
Representational similarity (Spearman *ρ*) between the best layer of an AlexNet-style CustomCNN and the THINGS behavioural similarity RDM, as a function of supervisory granularity (2, 4, 8, 16, 32, 64 classes on a log₂-scaled broken x-axis). The trained model is the same 5-conv / 2-FC CustomCNN throughout; only the coarse labels differ. Four PCA label sources are overlaid: AlexNet (light blue circles), CLIP ViT-L/14 (dark blue squares), supervised ViT-L/16 (crimson triangles), and DINOv3 ViT-L/16 (teal pentagons); in each case labels come from recursive median splits of the first six PCs of that source's FC features. The 1,000-class supervised baseline is shown as an orange diamond at the broken-axis 1,000 position, with a dashed orange reference line and a torn pale-orange 95% CI band extending across the coarse region; the grey dashed line is the untrained-network baseline (epoch 0). The panel is rendered by reusing `fig4.panel_coarseness.plot_coarseness` unchanged and monkey-patching its architecture list to the four PCA sources, so layout and styling are structurally identical to main Fig. 4b.
All four label sources place their coarse-trained models near or above the 1,000-class baseline across 2–64 classes. CLIP-derived labels attain the highest absolute alignment and AlexNet-derived labels the lowest, but the coarseness curve is qualitatively flat-above-baseline for every source.
Error bars and the 1,000-way band are 95% bootstrap confidence intervals (1,000 iterations, 90% sub-sample, element-wise averaged across the three training seeds per condition). RSA is computed on the 80% concept-level THINGS evaluation split with the best layer selected on the 20% layer-selection split, both with `random_state=42`.
