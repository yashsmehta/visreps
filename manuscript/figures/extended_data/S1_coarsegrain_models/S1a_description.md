# Extended Data Fig. 1a: Neural alignment across all four PCA label sources

**Extended Data Fig. 1a | The coarseness–alignment relationship in visual cortex is independent of the pretrained model used to define the labels.**
Raw representational similarity (Spearman *ρ*) between the best layer of an AlexNet-style CustomCNN and neural RDMs, as a function of supervisory granularity (2, 4, 8, 16, 32, 64 classes on a log₂-scaled, broken x-axis). In every panel the trained model is the same 5-conv / 2-FC CustomCNN; only the labels differ across conditions. Four PCA label sources are overlaid: AlexNet (ImageNet-supervised, light blue circles), CLIP ViT-L/14 (dark blue squares), a supervised ViT-L/16 (`vit_large_patch16_224`; crimson triangles), and DINOv3 ViT-L/16 (`vit_large_patch16_dinov3`; teal pentagons). For every source, coarse labels are obtained by recursive median splits of the first six principal components of that source's FC features on ImageNet. The 1,000-class supervised baseline (orange diamond, dashed orange reference line) is the standard ImageNet-trained CustomCNN; the grey dashed line marks the untrained-network baseline (epoch 0). Marker positions at each cfg are jittered horizontally to reduce overplotting; visual style reuses `fig3.panel_raw.plot_raw` unchanged and monkey-patches the architecture list to the four sources, so y-limits are force-matched to the corresponding panels of main Fig. 3.
**a**, Macaque TVSD V1. **b**, Macaque TVSD IT. **c**, Human NSD early visual stream. **d**, Human NSD ventral visual stream. Early regions (**a**, **c**) are approximately flat across granularity for all four label sources; higher regions (**b**, **d**) rise gradually with granularity and converge near the 1,000-class baseline by 32–64 classes. The same qualitative pattern across a CNN, a contrastive VLM, a supervised ViT and a self-supervised ViT indicates that the effect tracks the granularity of the label partition rather than the geometry of the source model.
Error bars are 95% bootstrap confidence intervals (1,000 iterations, 90% sub-sample) computed per run and element-wise averaged across all runs in a condition, where a condition aggregates three training seeds × subjects (8 for NSD, 2 for TVSD).
