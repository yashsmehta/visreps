# Extended Data Fig. 2b: THINGS behavioural alignment with WordNet-derived coarse labels

**Extended Data Fig. 2b | WordNet-derived coarse labels match or exceed the 1,000-class baseline on human behavioural similarity.**
Representational similarity (Spearman *ρ*) between the best layer of an AlexNet-style CustomCNN and the THINGS behavioural similarity RDM, as a function of supervisory granularity. Labels are obtained by cutting the WordNet hypernym tree at fixed depths 1–7 from the root (longest hypernym path per ImageNet class); the number of unique ancestor synsets at each depth yields partitions of 2, 3, 4, 10, 20 and 57 classes (forest-green hexagons; `experiments/wordnet/make_wordnet_labels.py`). No learned visual features enter the label-generation procedure. The 1,000-class supervised baseline (orange diamond at the broken-axis 1,000 position, with a torn pale-orange 95% CI band extending across the coarse region) and the untrained-network baseline (grey dashed line, epoch 0) are the same standard ImageNet-trained CustomCNN used throughout the paper. The panel is drawn by `S2_wordnet.plot_wordnet_scatter` with the same broken-axis / jittered-marker layout as main Fig. 4b.
WordNet-derived coarse models match or exceed the 1,000-class baseline at every granularity level, mirroring the PCA-based behavioural result in main Fig. 4 and Extended Data Fig. 1b. The convergence across two fundamentally different label-generation procedures — PCA of learned visual features versus a lexical-semantic graph cut — is consistent with the coarseness effect depending on the granularity of the partition rather than on any particular feature space used to define category boundaries.
Error bars are 95% bootstrap confidence intervals (1,000 iterations, 90% sub-sample) from `plotter_utils.get_condition_summary`, computed on the 80% concept-level THINGS evaluation split (fixed `random_state=42`). For WordNet the `results.db` currently contains a single training seed (seed = 1), so the interval at each point reflects within-run stimulus-level resampling only, not seed variability.
