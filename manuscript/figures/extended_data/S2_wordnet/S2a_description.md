# Extended Data Fig. 2a: Neural alignment with WordNet-derived coarse labels

**Extended Data Fig. 2a | Coarse labels derived from the WordNet noun hierarchy reproduce the neural coarseness pattern of main Fig. 3 without using any learned visual representation.**
Raw representational similarity (Spearman *ρ*) between the best layer of an AlexNet-style CustomCNN and neural RDMs, as a function of supervisory granularity, for labels constructed directly from the WordNet noun hierarchy. Each ImageNet class is mapped to its ancestor synset along the longest hypernym path at fixed depths 1–7 from the root, and the number of unique ancestors at each depth defines the partition: 2, 3, 4, 10, 20 and 57 classes (forest-green hexagons; `experiments/wordnet/make_wordnet_labels.py`). No visual features are used — only WordNet graph structure. The 1,000-class supervised baseline (orange diamond with a torn CI band bounded by a dashed orange reference line) and the untrained-network baseline (grey dashed line, epoch 0) are the standard ImageNet-trained CustomCNN and its untrained initialization; x-axis break and jittered marker placement reuse `fig3.panel_raw.plot_raw`, with y-limits force-matched to the corresponding panels of main Fig. 3.
**a**, Macaque TVSD V1. **b**, Macaque TVSD IT. **c**, Human NSD early visual stream. **d**, Human NSD ventral visual stream. Early regions (**a**, **c**) are approximately flat across WordNet granularity; higher regions (**b**, **d**) rise gradually and converge near the 1,000-class baseline — the same qualitative pattern reported for PCA-based labels in main Fig. 3, obtained from a fundamentally different label-construction procedure.
Error bars are 95% bootstrap confidence intervals (1,000 iterations, 90% sub-sample) computed per run via `plotter_utils.get_condition_summary` and element-wise averaged across runs. For WordNet the `results.db` currently contains a single training seed (seed = 1); the error bar at each point therefore reflects within-run stimulus-level bootstrap resampling aggregated across subjects (8 for NSD, 2 for TVSD), not across training-seed variability.
