# Extended Data Fig. 3: Encoding-model analysis replicates the neural alignment results from main Fig. 3

**Extended Data Fig. 3 | Voxelwise encoding-score alignment reproduces the RSA-based coarseness pattern of main Fig. 3.**
Neural alignment quantified by the held-out Pearson correlation between `RidgeCV`-predicted and measured responses in a voxelwise linearised encoding model (`analysis = "encoding_score"`, `compare_method = "pearson"`). Activations from every layer of an AlexNet-style CustomCNN are projected with a fixed sparse random projection to *k* = 4,096 dimensions; per run, the best layer is selected on an 80/20 fit–validation split with `RidgeCV(cv=5)`, then refit on the full training set and evaluated on the held-out test stimuli (see Methods). Two PCA label sources are overlaid per panel: AlexNet (light blue circles) and CLIP ViT-L/14 (dark blue squares); ViT-L/16 and DINOv3 sources are absent because no encoding-score rows were run for them, and pixel-derived labels are absent for the same reason (noted inline in `S3_encoding_scores.py`). The 1,000-class supervised baseline is the standard ImageNet CustomCNN (orange diamond at the broken-axis 1,000 position, with a torn pale-orange 95% CI band and a dashed orange reference line across the coarse region); the grey dashed line marks the untrained-network baseline (epoch 0). Layout and styling reuse `fig3.panel_raw.plot_raw` with the fetchers monkey-patched to the encoding-score / Pearson fetchers (`fetch_arch_data_enc`, `fetch_baseline_ci_enc`) — the visual grammar is therefore identical to main Fig. 3 and y-limits are set automatically by `plot_raw` rather than force-matched.

Above each scatter, a narrow **lollipop strip** (`plot_lollipop_enc`) reports, for each PCA source, *k*\* — the smallest granularity in {2, 4, 8, 16, 32, 64} whose 95% CI upper bound first reaches the 1,000-class baseline's 95% CI lower bound. Stems run from the left edge of the axis to *k*\* and are capped with the source's marker; an em-dash is shown if no coarse condition reaches the baseline band. The dashed vertical line marks the 1,000-way position.
**a**, Macaque TVSD V1. **b**, Macaque TVSD IT. **c**, Human NSD early visual stream. **d**, Human NSD ventral visual stream. Early regions (**a**, **c**) are flat across granularity; higher regions (**b**, **d**) rise and converge near the 1,000-class baseline by 32–64 classes — the same pattern seen with RSA in main Fig. 3.
Error bars and shaded bands are 95% bootstrap confidence intervals (1,000 iterations, 90% sub-sample) computed per run and element-wise averaged across runs, where a condition aggregates three training seeds × subjects (8 for NSD, 2 for TVSD).
