# Extended Data Fig. 6b: THINGS behavioural alignment persists across representational dimensionality

**Extended Data Fig. 6b | The coarse-model advantage on human behavioural similarity persists across the full range of retained representational dimensions.**
Representational similarity (Spearman *ρ*) between model FC1 activations and the THINGS behavioural similarity embedding as a function of the number of top principal components retained from the best-layer activations (*k* = 1, 2, …, 50). The best coarse model (blue) is a 64-class supervised ViT-L/16; the 1,000-class supervised baseline is shown in orange and the untrained-network baseline as a grey dotted line. Shaded bands denote 95% bootstrap confidence intervals.
Both curves plateau by *k* ≈ 10–20 PCs, and the coarse model's advantage over the 1,000-class baseline is maintained at every dimensionality from *k* = 1 through *k* = 50. The structural correspondence with human similarity judgements is therefore not confined to a low-dimensional subspace but persists as the representational space expands toward its full rank, ruling out a dimensionality-matching artifact as an explanation for the behavioural coarseness advantage.
