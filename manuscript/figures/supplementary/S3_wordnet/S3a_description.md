# Supplementary Figure 3a: Neural alignment with WordNet-derived coarse labels

**Supplementary Fig. 3a | Coarse labels derived from the WordNet noun hierarchy reproduce the neural coarseness pattern of main Fig. 3 without using any learned visual representation.**
Raw representational similarity (Spearman *ρ*) as a function of supervisory granularity for labels constructed entirely from the WordNet lexical-semantic taxonomy: the 1,000 ImageNet synsets are clustered by hierarchical agglomerative clustering on pairwise Wu–Palmer similarity, yielding partitions at 2, 3, 4, 10, 20 and 57 classes (forest-green hexagons). This procedure uses no image features whatsoever — only distances between English nouns. The 1,000-class supervised baseline is marked by an orange diamond and the untrained-network baseline by a grey dashed line. Broken x-axis and jittered markers match main Fig. 3.
**a**, Macaque TVSD V1. **b**, Macaque TVSD IT. **c**, Human NSD early visual stream. **d**, Human NSD ventral visual stream. Early visual regions (**a**, **c**) are flat across WordNet granularity levels, while higher visual regions (**b**, **d**) show a gradual increase that converges near the 1,000-class baseline — the same qualitative pattern reported for PCA-based labels in main Fig. 3, obtained from a fundamentally different label-construction procedure. The neural coarseness effect is therefore a general property of coarse supervision rather than an artifact of PCA-based label generation.
Error bars denote 95% bootstrap confidence intervals aggregated across subjects (or monkeys) and three independently trained networks per condition.
