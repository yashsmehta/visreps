# Supplementary Figure 5: Per-layer RSA profiles across all granularity levels

**Supplementary Fig. 5 | Per-layer representational similarity profiles reveal layer-dependent effects of label coarseness.**
Representational similarity (Spearman *ρ*) between each of the seven CNN layers (conv1–conv5, fc1, fc2) and the neural or behavioural reference data, shown for every granularity level tested: 2, 4, 8, 16, 32 and 64 classes (blue gradient, light to dark), the 1,000-class supervised baseline (orange) and an untrained-network baseline (grey dashed). The PCA source architecture that maximises alignment on held-out data is auto-selected per benchmark. Whereas main figures report only the best-performing layer for each model, this figure shows the full layer hierarchy for every condition.
**a**, Macaque TVSD V1. **b**, Macaque TVSD V4. **c**, Macaque TVSD IT. **d**, Human NSD early visual stream. **e**, Human NSD ventral visual stream. **f**, THINGS behavioural alignment. In early visual regions (**a**, **d**), per-layer profiles overlap almost completely across granularity levels, providing an independent confirmation of the flat coarseness curves of main Fig. 3 from the perspective of individual layers rather than best-layer selection. In higher visual regions (**c**, **e**) and for behavioural alignment (**f**), the profiles fan out at deeper layers: coarser models peak at intermediate layers (fc1), whereas finer-grained models peak at the deepest layer (fc2). For THINGS behavioural alignment (**f**), coarse models achieve higher alignment than the 1,000-class baseline at every layer of the network — the coarseness advantage pervades the entire feature hierarchy rather than emerging only at a single representational bottleneck.
