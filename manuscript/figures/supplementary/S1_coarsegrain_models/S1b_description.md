# Supplementary Figure 1b: THINGS behavioural alignment across all four PCA label sources

**Supplementary Fig. 1b | The coarse-supervision advantage on human behavioural similarity replicates across all four PCA label sources.**
Representational similarity (Spearman *ρ*) between model FC1 activations and the THINGS behavioural similarity embedding, as a function of supervisory granularity (2–64 classes, log₂ scale), with four PCA label sources overlaid: AlexNet (light blue circles), CLIP ViT-L/14 (dark blue squares), supervised ViT-L/16 (crimson triangles) and DINOv3 (teal pentagons). The 1,000-class supervised baseline is marked by an orange diamond and the untrained-network baseline by a grey dashed line. Broken x-axis and jittered markers match main Fig. 4.
All four label sources produce coarse-trained models that substantially exceed the 1,000-class baseline at every granularity level. CLIP-derived labels yield the highest absolute alignment and AlexNet-derived labels the lowest, but the shape of the coarseness curve — a plateau above the fine-grained baseline across 2–64 classes — is qualitatively identical across sources. The behavioural advantage of coarse supervision is therefore not contingent on the specific representational geometry used to define the label boundaries.
Error bars denote 95% bootstrap confidence intervals (1,000 iterations) aggregated across three independently trained networks per condition, computed on the 80% concept-level THINGS evaluation split.
