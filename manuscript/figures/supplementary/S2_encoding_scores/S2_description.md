# Supplementary Figure 2: Encoding-model analysis replicates the neural alignment results from main Fig. 3

**Supplementary Fig. 2 | Neural alignment measured by voxelwise encoding score reproduces the RSA-based coarseness pattern of main Fig. 3.**
Neural alignment quantified as the held-out Pearson correlation between `RidgeCV`-predicted and measured neural responses in a voxelwise linearised encoding model. Model activations are projected with a fixed sparse random projection to *k* = 4,096 dimensions; the best layer is selected on an 80/20 fit–validation split with 5-fold cross-validation, then refit on the full training set and evaluated on held-out test stimuli (see Methods). Two PCA label sources are overlaid per panel: AlexNet (light blue circles) and CLIP ViT-L/14 (dark blue squares); the 1,000-class supervised baseline is shown as an orange diamond. Pixel-derived labels are omitted because no pixel-baseline encoding-score runs are present in the results database. The x-axis is broken before the 1,000-class position and markers are jittered; layout and visual style match main Fig. 3.
**a**, Macaque TVSD V1. **b**, Macaque TVSD IT. **c**, Human NSD early visual stream. **d**, Human NSD ventral visual stream. Early visual regions (**a**, **c**) show flat coarseness profiles across granularity levels, while higher visual regions (**b**, **d**) exhibit a gradual increase that converges near or above the 1,000-class baseline by 32–64 classes — the same pattern reported with RSA in main Fig. 3. The consistency across two fundamentally different alignment metrics — one purely geometric (RSA), one predictive (encoding score) — indicates that the coarseness advantage reflects a genuine property of the learned representations rather than an artifact of any single evaluation procedure.
Error bars denote 95% bootstrap confidence intervals aggregated across subjects (or monkeys) and three independently trained networks per condition.
