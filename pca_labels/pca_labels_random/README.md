# Random class-level labels (control for the handcrafted semantic labels)

`n_classes_8.csv` assigns every image to one of eight groups by a **random,
balanced partition of the 1,000 ImageNet classes** (125 wnids per group,
`numpy.random.default_rng(42)`), generated by
`scripts/coarsegrain/make_random_labels.py`. `class_assignments.csv` lists the
wnid -> group mapping. Assignment is at the class level, so all images of a
class share a group, as with the handcrafted labels; the only thing removed is
the semantic coherence of the groups. Training config mirrors the handcrafted
run (`configs/grids/train_random.json`, one seed).
